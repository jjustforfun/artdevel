## The project

VibeAI Pro is a news aggregator dedicated to artificial intelligence: models, research, curiosities, tools and vibecoding.

## Features

- Automatic article aggregation from original sources.
- Automatic categorization and tagging (Models, Research, Curiosities, Tools, Vibecoding).
- Bilingual French / English interface.
- Trends section and tag-based search.
- Public API to consume the articles.
- Continuous updates and light / dark theme.
