## Проект

VibeAI Pro — агрегатор новостей об искусственном интеллекте: модели, исследования, любопытное, инструменты и vibecoding.

## Функции

- Автоматическая агрегация статей из первоисточников.
- Автоматическая категоризация и теги (Модели, Исследования, Любопытное, Инструменты, Vibecoding).
- Двуязычный интерфейс: французский / английский.
- Раздел трендов и поиск по тегам.
- Публичный API для доступа к статьям.
- Непрерывное обновление и светлая / тёмная тема.
